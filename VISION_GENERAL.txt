📦 ESTRUCTURA DEL PROYECTO
═══════════════════════════════════════════════════════════════════════════════

   browser-data-cleaner/
   ├─ src/
   │  ├─ adapters/          → Conectores por navegador (Chrome, Firefox, etc)
   │  ├─ core/              → Motor principal (Detector, Manager, Logs)
   │  ├─ utils/             → Utilidades (paths, dominios, FS)
   │  └─ model/             → Datos (dominios protegidos)
   │
   ├─ main.js              → Proceso principal Electron (IPC handlers)
   ├─ preload.js           → API segura renderer→main
   ├─ renderer.js          → Lógica de interfaz (200+ líneas)
   ├─ index.html           → Estructura HTML
   ├─ styles.css           → Diseño profesional + dark mode
   │
   └─ package.json         → Dependencias (Electron, SQLite3, UUID)


🎯 FUNCIONALIDADES PRINCIPALES
═══════════════════════════════════════════════════════════════════════════════

   1️⃣  GESTIONAR DOMINIOS PROTEGIDOS
       ✓ Crear lista editable
       ✓ Agregar/Quitar dominios
       ✓ Buscar por nombre o dominio
       ✓ Importar/Exportar JSON
       ✓ Preconfigurados: Google, GitHub, Claude (21 dominios)

   2️⃣  LIMPIAR DATOS DE NAVEGADORES
       ✓ Detecta automáticamente 9 navegadores instalados
       ✓ Borra TODO excepto dominios protegidos
       ✓ Historial, Cookies, Cache, LocalStorage, etc.
       ✓ Confirmación ANTES de cada operación

   3️⃣  LIMPIAR DATOS DE UN DOMINIO
       ✓ Escribe o pega el dominio (ej: metabet.tv)
       ✓ Borra sus datos en TODOS los navegadores
       ✓ Valida que no esté en dominios protegidos
       ✓ No toca el resto de sitios

   4️⃣  RESPALDAR DATOS
       ✓ Crear backups timestamped
       ✓ Elegir qué respaldar (Historia, Cookies, etc)
       ✓ Estructura: BrowserBackup/[Nav]/[Timestamp]/

   5️⃣  VER REGISTRO DE ACTIVIDAD
       ✓ Log persistente con timestamps
       ✓ Todas las operaciones registradas
       ✓ Sin información sensible

🛠️ ARQUITECTURA TÉCNICA
═══════════════════════════════════════════════════════════════════════════════

   RENDERER (UI)
   ↓ (IPC - preload.js)
   MAIN PROCESS
   ├─ BrowserManager
   │  ├─ BrowserDetector → Detecta navegadores
   │  ├─ ChromiumAdapter → Opera sobre Chrome, Edge, etc
   │  └─ FirefoxAdapter  → Opera sobre Firefox, LibreWolf, etc
   │
   ├─ DomainMatcher
   │  ├─ Coincidencia exacta: github.com = github.com
   │  ├─ Wildcard: *.github.io = user.github.io
   │  └─ Protección: no borra dominios en lista
   │
   ├─ FsUtils
   │  └─ Operaciones seguras de archivos
   │
   └─ ActivityLog
      └─ Registro persistente
