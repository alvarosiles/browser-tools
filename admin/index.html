IT Support Tools — Instaladores

Panel interno con los comandos y archivos de instalación del agente local.

Windows

PowerShell — instala y registra el servicio automáticamente.

irm https://alvarosiles.github.io/browser-tools/downloads/install.ps1 | iex
⬇ BrowserToolsAgent.exe ⬇ install.ps1

Linux

Bash — descarga Node.js, instala dependencias y registra un servicio systemd de usuario.

curl -fsSL https://alvarosiles.github.io/browser-tools/downloads/install.sh | bash
⬇ install.sh ⬇ install-linux.sh
