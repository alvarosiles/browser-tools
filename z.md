# 26. 🔒 SEGURIDAD DE LA APLICACIÓN

La aplicación debe funcionar bajo el principio de mínimo privilegio.

IMPORTANTE:

* No almacenar contraseñas en texto plano.
* No enviar información del PC a servidores sin consentimiento.
* No subir backups automáticamente sin autorización.
* No ejecutar comandos administrativos silenciosamente.
* Mostrar cuándo una operación requiere administrador.
* Confirmar operaciones destructivas.
* Registrar operaciones realizadas.
* Validar rutas antes de eliminar archivos.
* Proteger procesos críticos de Windows.
* Evitar comandos construidos directamente desde input del usuario.
* Utilizar APIs oficiales de Windows siempre que sea posible.
* Separar claramente las operaciones que requieren privilegios elevados.
* No intentar saltarse UAC.
* No ocultar procesos ni persistencia.
