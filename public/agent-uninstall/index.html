Desinstalar agente local

Elimina por completo el agente de esta PC — solo afecta a la máquina desde donde se abre esta página.

Esto detiene el servicio, quita el arranque automático (registro de Windows o unidad systemd) y borra los archivos instalados. Después de confirmar, esta página ya no podrá volver a conectarse al agente. Para reinstalarlo hay que correr el comando de instalación de nuevo.
