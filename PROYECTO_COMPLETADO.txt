🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════

1️⃣  INSTALAR
    $ npm install

2️⃣  EJECUTAR
    $ npm start

3️⃣  VER DOMINIOS PROTEGIDOS
    Abre la app → Sidebar → 🛡️ Dominios Protegidos
    (Ya tienes Google, GitHub, Claude configurados)

4️⃣  LIMPIAR DATOS SEGURAMENTE
    Sidebar → 🌐 Navegadores Instalados
    Presiona "🧹 Limpiar" en cualquier navegador
    Confirma en el diálogo
    → Se borran todos los datos EXCEPTO los protegidos

5️⃣  LIMPIAR UN DOMINIO ESPECÍFICO
    Sidebar → 🧹 Borrar Datos de un Dominio
    Escribe: metabet.tv
    Presiona "🧹 Borrar"
    → Se borra SOLO ese dominio en TODOS los navegadores

6️⃣  CREAR RESPALDO
    Sidebar → 🌐 Navegadores Instalados
    Presiona "💾 Backup" en un navegador
    Selecciona qué respaldar (Historia, Cookies, etc)
    → Se crea en: ~/BrowserBackup/[Navegador]/[Timestamp]/

7️⃣  VER ACTIVIDAD
    Sidebar → 📋 Actividad
    Ves el registro de todas las operaciones


📊 FUNCIONALIDADES POR SECCIÓN
═══════════════════════════════════════════════════════════════════════════════

🌐 NAVEGADORES INSTALADOS
   ├─ Detecta automáticamente qué navegadores tienes
   ├─ Muestra estado (✓ Instalado / ✗ No instalado)
   ├─ Botones por navegador:
   │  ├─ 🧹 Limpiar (borra TODO excepto protegidos)
   │  └─ 💾 Backup (crea respaldo timestamped)
   └─ Selecciona tipos de datos a respaldar

🛡️ DOMINIOS PROTEGIDOS
   ├─ Tabla con lista actual de dominios
   ├─ Búsqueda en tiempo real
   ├─ Botón: ＋ Agregar dominio
   ├─ Botón por dominio: Quitar
   ├─ 📥 Importar (cargar lista JSON)
   └─ 📤 Exportar (guardar lista JSON)

🧹 BORRAR DATOS DE UN DOMINIO
   ├─ Input: escribe/pega un dominio o URL
   │  (ejemplo: "metabet.tv" o "https://metabet.tv/es/")
   ├─ Detecta automáticamente el dominio desde la URL
   ├─ Valida: si está protegido → muestra advertencia
   ├─ Borra en: TODOS los navegadores compatibles
   └─ Borra: Cookies, Historial, Permisos, Datos guardados

📋 REGISTRO DE ACTIVIDAD
   ├─ Log persistente con timestamps
   ├─ Todas las operaciones registradas
   ├─ Sin información sensible (no guarda contraseñas, tokens, etc)
   └─ Botón: 🗑️ Limpiar logs


🔐 SEGURIDAD - LO QUE LA DIFERENCIA
═══════════════════════════════════════════════════════════════════════════════

❌ LO QUE NO HACE (a diferencia de otras apps):
   • NO envía datos a servidores
   • NO guarda contraseñas en logs
   • NO elimina dominios protegidos silenciosamente
   • NO borra datos si el navegador está abierto (advierte)
   • NO hace "borrar todo y restaurar" (es inseguro)

✅ LO QUE SÍ HACE:
   • Permite proteger dominios críticos (GitHub, Google, Claude)
   • Borra SOLO los datos no protegidos
   • Confirmación ANTES de cada operación
   • Registro detallado de qué se borró/respaldó
   • Acceso seguro a BDs via SQLite
   • Coincidencia inteligente de dominios (incluyendo wildcards)
